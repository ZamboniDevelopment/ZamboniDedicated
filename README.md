# ZamboniDedicated
- Somewhat mimics the original servers on how they used to serve clients regarding Online Team Play
- Targeting DirtySDK 8.x
- This server handles game traffic only. Consoles must be directed to it by a matchmaking backend
- There is still room for improvements
- Sources: analyzing network captures/game behaviour, research and reverse engineering
## Compatibility
- Working on: NHL 11 to NHL Legacy
- Broken on: NHL 10
- Similar titles might be reusing same protocols
